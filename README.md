# Nixie-Tube-Clock

A project of Nixie tube clock.

## Hardware

- Powered by 12V DC charger

## Functions

- Clock with hour and minute
- Temperature
- Humidity
- Time setting mode
- de-poisoning the nixie tube every hour

## Library

List of the libraries used in this project:

- [Adafruit AM2320 sensor library](https://github.com/adafruit/Adafruit_AM2320) (by Adafruit)
- [DS3231](https://github.com/NorthernWidget/DS3231) (by Andrew Wickert)
- [RotaryEncoder](https://github.com/mathertel/RotaryEncoder) (by Matthias Hertel)
