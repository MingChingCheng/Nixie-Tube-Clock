# Nixie-Tube-Clock

A project of Nixie tube clock.

## Hardware

- Powered by 12V DC charger (5.5x2.1)
- Whole module cost ~0.25A or 3W power
- 4 nixie tubes - IN-8
- Use Real time clock - DS3231
- Use Humidity sensor - AM2320

## Functions

- Time mode, display time with hour and minute
- Temperature mode
- Humidity mode
- Time setting mode
- De-poisoning the nixie tubes every hour

## Library

List of the libraries used in this project:

- [Adafruit AM2320 sensor library](https://github.com/adafruit/Adafruit_AM2320) (by Adafruit)
- [DS3231](https://github.com/NorthernWidget/DS3231) (by Andrew Wickert)
- [RotaryEncoder](https://github.com/mathertel/RotaryEncoder) (by Matthias Hertel)
